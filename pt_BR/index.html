Uma camada de orquestração para dados de mercado, preços, analytics e estratégias. Combina políticas limitadas por tempo, backfills de fontes oficiais, provedores alternativos, observabilidade e finalização fail-closed para saídas críticas.

  • Backfills retomáveis
  • Validações fail-closed

@flow(timeout_seconds=politica.limite)
def ingerir_dados(data):

    precos = paralelo(buscar_precos, simbolos)
    validar_cobertura(precos)
    finalizar_atomicamente(data, precos)
